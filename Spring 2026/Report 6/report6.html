I think the best way to find the ground-truth peak is to find a place to cut the data into thirds into two subsets (because there are usually two peaks in every graph) and then take the maximum of that time period in terms of emergency department visits and then compare that peak 1 and peak 2 in state and HSA levels. The differences can be logged in a data set where we have the HSA, State, Peak Number (1-3), Truth Time Diff, Truth Magnitude Diff, DTW Metrics, and then Frechet in one line and then three lines for every HSA (each peak) so that we get 2013 rows (671 * 3). To understand where to cut the time-series data in half, I cycled through some graphs. I decided on cutting the graph at week index 50 and week index 100. Then, we can start the scatter plots!

Finding the ground truth

The truth_diff values are always HSA - state. A positive time difference means that the HSA has a later peak and a positive magnitude difference means that the HSA has a larger peak.

all_metrics_modified = all_metrics |>
  mutate(week_index = (epi_week + (epi_year - 2022) * 52 - 38),
    peak_window = case_when(
      week_index <= 50  ~ 1,
      week_index <= 100 ~ 2,
      TRUE              ~ 3
  ))

truth_peaks =
  all_metrics_modified |>
  group_by(ID, state, peak_window) |>
  summarise(
    # HSA peak
    hsa_peak_week  = week_index[which.max(inc_hsa)],
    hsa_peak_value = max(inc_hsa, na.rm = TRUE),

    # State peak
    state_peak_week  = week_index[which.max(inc_state)],
    state_peak_value = max(inc_state, na.rm = TRUE),

    # Differences
    truth_time_diff = hsa_peak_week - state_peak_week,
    truth_time_diff_abs = abs(truth_time_diff),
    truth_mag_ratio  = hsa_peak_value / state_peak_value,

    .groups = "drop"
  )

metrics_unique =
  all_metrics_modified |>
  group_by(ID, state) |> 
  filter(week_index == 2) |> 
  summarise(
    mean_abs_lag,
    signed_lag,
    lag_sd,
    dtw_mae,
    dtw_rmse,
    rmse,
    amp_ratio,
    dtw_amp_ratio,
    lag_amp_corr,
    frechet,
    .groups = "drop"
  )

diff_peak_data =
  truth_peaks |> left_join(metrics_unique,
            by = c("ID", "state"))

These hold upon zooming in (frechet and DTW_RMSE) very well! Basically, the more variation a variable, the more likely can latch onto a general trend and look correlated with a good linear regression. However, if focusing on the “nucleus” of the data, it is hard to find a good line if there is no real trend. By zooming in, we can see if there is a real trend in the core of the data.

magnitude_cor_table = diff_peak_mag |>
