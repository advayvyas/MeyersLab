Introduction

pred_baseline = predict(baseline, newdata = df_complete)
obs = df_complete$diff_wis_season

R2 = 1 - sum((obs - pred_baseline)^2)/sum((obs - mean(obs))^2)
RMSE = sqrt(mean((obs - pred_baseline)^2))
set.seed(123)

K = 10
folds = sample(rep(1:K, length.out = nrow(df_complete)))

cv_R2_values = c()

for (k in 1:K) {
    train_idx = which(folds != k)
    test_idx = which(folds == k)

    m = lm(diff_wis_season ~ pop_ratio + pct_urban + density_ratio +
        n_hsa + area_ratio + education_diff + income_diff + poverty_diff +
        unemployment_diff, data = df_complete[train_idx, ])

    pred_k = predict(m, newdata = df_complete[test_idx, ])
    obs_k = df_complete$diff_wis_season[test_idx]

    R2_k = 1 - sum((obs_k - pred_k)^2)/sum((obs_k - mean(obs_k))^2)
    cv_R2_values[k] = R2_k
}

cv_mean_R2 = mean(cv_R2_values)
baseline_predictions = data.frame(estimate = pred_baseline, observed = obs)

ggplot(baseline_predictions, aes(x = estimate, y = observed)) +
    geom_point(alpha = 0.7) + geom_abline(slope = 1, intercept = 0,

pvals_baseline = summary(baseline)$coefficients[, "Pr(>|t|)"]

b = ggplot(data.frame(term = names(pvals_baseline), pvalue = pvals_baseline),

    theme_minimal() + theme(axis.text.x = element_blank())

bo = ggplot(data.frame(term = names(pvals_outlier), pvalue = pvals_outlier),
    aes(x = term, y = pvalue)) + geom_col(fill = "tomato", col = "black") +
    labs(title = "Outlier-Removed Baseline Model Coefficient P-values") +
    theme_minimal() + theme(axis.text.x = element_text(angle = 45,
    hjust = 1))

b/bo

This baseline model mainly just serves to check how well the more complex models compare to a practically “naive” estimate of the difference between state and HSA. Both linear regression models (outlier and regular) both have n_hsa as the most important coefficient followed by density_ratio and then education_diff. While not identical, they maintain the ordering for the top three most significant coefficients. However, the outlier-removed model drops density_ratio and education_diff p-values into a very significant range at below 0.01.

These baseline models and outlier-removal will be useful in the upcoming sections to test against the XGBoost and BART models since they have solid RMSE and \(R^2\) metrics. For reference, the outlier-removed model improves in every metric.
